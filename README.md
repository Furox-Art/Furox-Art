## 🔭 Featured project

### [cognitive-discovery-system](https://github.com/Furox88/cognitive-discovery-system)

An open-source computational science platform: **19 modules, zero runtime
dependencies**, published on [PyPI](https://pypi.org/project/cognitive-discovery-system/).

![PyPI](https://img.shields.io/pypi/v/cognitive-discovery-system.svg)
![CI](https://github.com/Furox88/cognitive-discovery-system/actions/workflows/tests.yml/badge.svg)
![Coverage](https://codecov.io/gh/Furox88/cognitive-discovery-system/branch/main/graph/badge.svg)
![License](https://img.shields.io/badge/License-MIT-blue.svg)

**What's inside (all from scratch, all readable):**

- 🎛 Quantum circuit simulation — single/multi-qubit, Bell/GHZ states
- 📈 Statistics — t-tests, ANOVA, effect sizes, nonparametric rank tests,
  time-series analysis
- 🤖 Machine learning — PCA, k-means, k-NN, decision trees, logistic/linear
  regression, neural networks, even a mini-GPT with its own autograd engine
- 🌊 Signal processing — radix-2 FFT, Butterworth filter design, power spectra
- ⏱ ODE solvers — RK4/RK45 plus implicit stiff solvers (backward Euler,
  Crank–Nicolson)
- 🧮 The math underneath — incomplete gamma/beta via Numerical Recipes,
  LU/QR/Cholesky, Monte Carlo, symbolic differentiation

**Engineering standards:** 1,693 tests · 100% statement *and* branch coverage
(enforced CI gate) · `mypy --strict` · signed releases with build provenance.
